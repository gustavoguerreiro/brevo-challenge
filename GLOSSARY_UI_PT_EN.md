# Interface glossary: Portuguese to English

The test account was set to Portuguese, so the catalog quotes Portuguese button names, menu entries, block names and messages (`ui_label_pt` and the numbered UI steps). Everything else in the catalog (ids, summaries, rules, guide) is in English.

**Read this first.** These are literal translations written by the model that built the catalog. They were **not** captured from an English interface: nobody switched the account to English, so Brevo's own English wording may differ (a button may read "Add users", "Invite users" or something else). Treat the English column as a guide to what the Portuguese label means, and match on the route, the position on the screen and the icon when the wording does not match. The routes, ids and API calls do not change with the language. Attribute ids do (`NOME`, `SOBRENOME` in Portuguese): see `AGENT_GUIDE.md`.

The Actions column counts the catalog entries that quote the string. The same data is in `reference/ui_glossary_pt_en.json`. 474 strings.
