# Curated map from Brevo public API operations to catalog action ids.
# This file is the human/AI-reviewed layer on top of the machine-generated inventory.
# Columns: METHOD path | id | flags | note
# flags (space separated):
#   ext        risk external_effect (reaches real recipients, third parties, billing or credentials)
#   conf       requires_human_confirmation
#   write      force risk=write (default for DELETE is destructive)
#   destructive force risk=destructive
#   read       force risk=read (POST used as a read)
#   live       operation exists only in the live developer-site spec (not in the Feb 2025 SDK snapshot)
#   removed    operation is in the Feb 2025 snapshot but absent from the live spec: not catalogued
#   dup        collapsed into another row in the live spec: not catalogued
#   handwritten covered by a hand-written action file; the generator skips it
#   deprecated marked deprecated in the spec
# Verbs allowed in ids: see schema/action.schema.json.
